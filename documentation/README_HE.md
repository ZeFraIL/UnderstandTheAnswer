## 🎯 מטרת הפרויקט

- **הבעיה שהאפליקציה פותרת:** בלמידת מתמטיקה מסורתית, תלמידים מציבים נתונים בנוסחאות באופן מכני ומחשבים תוצאות באופן סביל. האפליקציה "Understand The Answer" הופכת את התהליך: התלמיד מקבל גרף או תוצאה מוכנה, ועליו לשחזר את הפרמטרים/התנאים המקוריים באמצעות כלים אינטראקטיביים.
- **חשיבות המשימה:** מפתח אינטואיציה מתמטית אקטיבית, חשיבה מרחבית, ניתוח ביקורתי ובדיקת היפותזות במקום שינון מכני.
- **קהל יעד:** תלמידי חטיבת ביניים ותיכון, מורים למתמטיקה, מורים פרטיים ולומדים עצמאיים המתרגלים גיאומטריה אנליטית ואלגברה.

## 📌 דרישות האפליקציה

### דרישות פונקציונליות
- מאמן מתמטי רב-נושאי ("נקודה במערכת צירים", "פונקציה קווית", "פונקציה ריבועית / פרבולה").
- רינדור גרפי אינטראקטיבי על גבי רכיבי Canvas מותאמים אישית (`CoordinatePlaneView`, `LinearFunctionView`, `ParabolaFunctionView`).
- כלי רמז אינטראקטיביים (גרירת נקודות רמז, הזזת ישרים מקבילים, בניית ישר על פי שתי נקודות, ציר סימטריה, נקודות על הגרף).
- מנגנון הגנה מפני מניפולציות / רמאות (רדיוס אזור אסור $R \le 2.0$ המונע הסרת רמזים ישירות על היעד).
- מפענח ביטויים אריתמטיים בזמן אמת (`MathExpressionEvaluator`) המאפשר הזנת ביטויים מתמטיים בכל שדות הקלט.
- לוקליזציה דו-לשונית מלאה (אנגלית / רוסית) עם החלפת שפה דינמית ושמירה ב-`SharedPreferences` (ברירת מחדל אנגלית בהפעלה ראשונה).
- חלונות דיאלוג קונטקסטואליים המספקים חוקים מפורטים ופתרונות מתמטיים שלב-אחר-שלב.

### דרישות לא-פונקציונליות
- **ביצועים:** רינדור Canvas חלק ב-60 FPS, הקצאת אובייקטי Paint/Path מראש, ללא חסימת נתיב ה-UI.
- **שימושיות:** עיצוב נקי בסטנדרט Material 3, אזורי מגע נוחים לגרירה באצבע, פריסה רספונסיבית.
- **אמינות:** אימות קלט קפדני, מניעת קרסות בעת שגיאות תחביר או חלוקה באפס.

## 🧠 ארכיטקטורה כללית

- **הגישה שנבחרה:** ארכיטקטורת View-Fragment מודולרית (תבנית MVC / Hybrid View-Driven).
- **סיבת הבחירה:** התאמה מושלמת למחזור החיים של Android View, תקורה נמוכה, עבודה ישירה מול Canvas וניהול מסכים גמיש באמצעות Fragments.
- **רכיבי המערכת העיקריים:**
  - `StartActivity`: מסך פתיחה עם לוגו, תיאור השיטה, בורר שפה ולחצן התחלה.
  - `TopicSelectionActivity`: מסך בחירת נושא מבוסס MaterialCard.
  - `MainActivity`: מעטפת ראשית המנהלת `FragmentContainerView` וסרגל כלים עליון עם דיאלוגים.
  - `CoordinatePointFragment`, `LinearFunctionFragment`, `ParabolaFunctionFragment`: מנהלי לוגיקת הלמידה.
  - `CoordinatePlaneView`, `LinearFunctionView`, `ParabolaFunctionView`: רכיבי View מותאמים אישית לגרפיקה.
  - `MathExpressionEvaluator`: מנוע חישוב ביטויים אריתמטיים.
  - `LanguageManager`: מנהל השפות ושמירת ההגדרות.

## 🧩 תיאור מפורט של המחלקות

### 📌 מחלקה: MainActivity
- **תפקיד:** אקטיביטי עטיפה ראשי המארח את פרגמנטי הנושאים וסרגל הכלים.
- **אחריות:** מקבל פרמטרים מ-`TopicSelectionActivity`, טוען את הפרגמנט המתאים ומנהל את לחצן העזרה בסרגל העליון.
- **מתודות עיקריות:**
  - `onCreate(Bundle savedInstanceState)` — אתחול הפריסה, הגדרת EdgeToEdge, סרגל הכלים וטעינת הפרגמנט.
  - `showHelpDialog()` — הצגת חלון דיאלוג MaterialAlertDialog עם חוקי הנושא בפורמט HTML.

### 📌 מחלקה: StartActivity
- **תפקיד:** מסך הכניסה של האפליקציה.
- **אחריות:** הצגת לוגו, שם האפליקציה, תיאור השיטה, כפתורי בחירת שפה (אנגלית / רוסית) וכפתור התחלה.

### 📌 מחלקה: TopicSelectionActivity
- **תפקיד:** מסך בחירת הנושאים.
- **אחריות:** הצגת הנושאים הזמינים בכרטיסיות MaterialCardView והפעלת `MainActivity` עם מזהה הנושא שנבחר.

### 📌 מחלקה: CoordinatePointFragment / LinearFunctionFragment / ParabolaFunctionFragment
- **תפקיד:** בקרים עבור הנושאים המתמטיים השונים.
- **אחריות:** יצירת משימות אקראיות, קישור רכיבי ה-View, אימות תשובות, חישוב פתרונות שלב-אחר-שלב והצגת משוב למשתמש.

### 📌 מחלקה: CoordinatePlaneView / LinearFunctionView / ParabolaFunctionView
- **תפקיד:** רכיבי גרפיקה מותאמים אישית ב-Canvas.
- **אחריות:** ציור רשת הצירים $[-15..+15]$, צירים, חצים, מספרים, גרפים של פונקציות, רמזים אינטראקטיביים ואזורי הגנה.

### 📌 מחלקה: MathExpressionEvaluator
- **תפקיд:** כלי לחישוב ביטויים מתמטיים.
- **אחריות:** ניתוח וחישוב בטוח של ביטויים אריתמטיים (לדוגמה `(7 - 3) / (4 - 2)`).

### 📌 מחלקה: LanguageManager
- **תפקיד:** מנהל הגדרות שפה.
- **אחריות:** שמירת השפה שנבחרה ב-`SharedPreferences` (ברירת מחדל `"en"`) והחלת השפה באמצעות `AppCompatDelegate`.

## 🔄 תרחיש עבודת האפליקציה

1. הפעלת האפליקציה -> `StartActivity` טוען את השפה השמורה (בהפעלה ראשונה - אנגלית).
2. המשתמש בוחר שפה לפי רצונו -> הממשק מתעדכן מיידית.
3. לחיצה על "Start" -> נפתח מסך `TopicSelectionActivity`.
4. בחירת נושא -> נפתח מסך `MainActivity` עם הפרגמנט המתאים.
5. הגרלת תנאים מתמטיים אקראיים.
6. אינטראקציה עם הגרף (גרירת רמזים, הזזת ישרים מקבילים, מציאת ציר סימטריה או חשיפת נקודות).
7. מנגנון ההגנה מונע גרירת רמזים ישירות על היעד ($R \le 2.0$).
8. הזנת ביטויים בשדות התשובה -> המנוע בודק את התשובה -> המשתמש מקבל משוב מיידי ודיאלוג פתרון מפורט.

## ⚙️ ניהול תהליכונים וביצועים

- **מודל תהליכונים:** נתיב ה-UI הראשי של אנדרואיד (Main/UI Thread) לרינדור קל ועדכון ממשק.

- **מניעת ANR ודליפות זיכרון:** שימוש בהקשרים קצרי טווח, הימנעות מראפנסים סטטיים ל-Views, ניהול `Runnable` באמצעות `removeCallbacks()`.
