# Документация класса: LanguageManager

---

## 1. Общая информация
- **Имя класса:** `LanguageManager`
- **Тип:** Utility Class (Статический менеджер языка)
- **Назначение класса:** Управляет сохранением выбора языка в `SharedPreferences` и применяет локаль ко всему приложению через `AppCompatDelegate`.
- **Взаимодействие с другими компонентами:** Вызывается из `StartActivity` и других компонентов для инициализации и переключения языка ("en" или "ru").

---

## 2. Переменные (поля класса)
| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `PREF_NAME` | `String` (static final) | Имя файла настроек (`app_language_prefs`). | В `getLanguage` и `setLanguage`. |
| `KEY_LANGUAGE` | `String` (static final) | Ключ языка (`selected_language`). | В `getLanguage` и `setLanguage`. |
| `LANG_EN` | `String` (static final) | Код английского языка (`"en"`). | Константа языка. |
| `LANG_RU` | `String` (static final) | Код русского языка (`"ru"`). | Константа языка. |

---

## 3. Методы класса

### Имя метода: `getLanguage(Context context)`
- **Возвращаемое значение:** `String` (Код языка, например `"en"` или `"ru"`).
- **Что делает:** Читает сохранённый язык из `SharedPreferences`. По умолчанию возвращает `"en"`.

### Имя метода: `setLanguage(Context context, String langCode)`
- **Возвращаемое значение:** `void`
- **Что делает:** Сохраняет `langCode` и применяет локаль через `AppCompatDelegate.setApplicationLocales(...)`.

### Имя метода: `initLanguage(Context context)`
- **Возвращаемое значение:** `void`
- **Что делает:** Применяет сохранённый язык при запуске.

## 6. Взаимодействие с другими компонентами
Сохраняет выбор в `SharedPreferences` и обновляет `AppCompatDelegate`.

---

## 7. Общая логика класса
Сохраняет язык на диск и указывает Android, какой файл ресурсов загружать (`values` или `values-ru`).

---

## 8. Объяснение простыми словами
`LanguageManager` — это **записная книжка переводчика**. При каждом открытии приложения он проверяет записную книжку, чтобы вспомнить, на каком языке вы предпочитаете читать!
