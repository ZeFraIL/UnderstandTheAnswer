# Документация класса: StartActivity

---

## 1. Общая информация
- **Имя класса:** `StartActivity`
- **Тип:** Activity (Стартовый экран приложения)
- **Назначение класса:** Служит начальным экраном приложения. Отображает логотип, название, описание методики «математики наоборот», переключатель языка (English / Русский) и кнопку «Начать» для перехода к выбору тем.
- **Взаимодействие с другими компонентами:** Инициализирует `LanguageManager` перед созданием макета, читает и применяет настройки языка, а также запускает `TopicSelectionActivity` через `Intent`.

---

## 2. Переменные (поля класса)
*(Класс не содержит полей класса; использует локальные переменные внутри `onCreate`).*

---

## 3. Методы класса

### Имя метода: `onCreate(Bundle savedInstanceState)`
- **Тип метода:** `protected`
- **Возвращаемое значение:** `void` (не возвращает значение).
- **Параметры:**
  | Имя | Тип | Описание |
  | :--- | :--- | :--- |
  | `savedInstanceState` | `Bundle` | Сохранённое состояние активности при пересоздании. |
- **Что делает метод (подробно):**
  1. Вызывает `LanguageManager.initLanguage(this)` перед созданием макета для применения сохранённого языка.
  2. Вызывает `super.onCreate(savedInstanceState)` и `EdgeToEdge.enable(this)`.
  3. Разворачивает макет `R.layout.activity_start`.
  4. Настраивает слушатель `WindowInsetsListener` на `@+id/start_main` для отступов системных панелей.
  5. Находит `toggleGroupLanguage` и подсвечивает кнопку текущего языка.
  6. Прикрепляет `addOnButtonCheckedListener` к переключателю для смены языка через `LanguageManager.setLanguage(...)`.
  7. Настраивает клик по кнопке `btnStart` для запуска `TopicSelectionActivity`.
- **Когда вызывается:** Автоматически вызывается системой Android при создании экрана.
- **Что важно понимать:** `LanguageManager.initLanguage(this)` должен вызываться ДО `super.onCreate()` и `setContentView()`, чтобы макет разворачивался с правильными строковыми ресурсами.

---

## 4. Жизненный цикл (Activity)
- **`onCreate()`:**
  - *Когда вызывается:* При первом создании экрана.
  - *Что происходит:* Инициализирует язык, активирует режим Edge-to-Edge, разворачивает UI и связывает обработчики нажатий.

---

## 5. Взаимодействие с интерфейсом (UI)
- **Элементы UI:**
  - `ImageView` (`@+id/ivAppIcon`): Отображает логотип `@drawable/app_icon`.
  - `TextView` (`@+id/tvAppTitle`, `@+id/tvAppSubtitle`): Название и подзаголовок.
  - `MaterialCardView` (`@+id/cardDescription`): Карточка с описанием методики.
  - `MaterialButtonToggleGroup` (`@+id/toggleGroupLanguage`): Переключатель языка с кнопками `btnLangEn` и `btnLangRu`.
  - `MaterialButton` (`@+id/btnStart`): Кнопка «Начать».

---

## 6. Взаимодействие с другими компонентами
- **Intents:** Создаёт `Intent` для `TopicSelectionActivity.class` и вызывает `startActivity(intent)`.

---

## 7. Общая логика класса
1. Открывается стартовый экран.
2. Проверяет сохранённый язык (по умолчанию English при первом запуске).
3. При нажатии на «Русский» язык приложения меняется на лету.
4. Нажатие на «Начать» переводит пользователя к выбору тем.

---

## 8. Объяснение простыми словами
`StartActivity` — это **входная дверь и стойка регистрации** в музее. Прежде чем войти в выставочные залы, вы стоите у входа, видите логотип, выбираете язык путеводителя (English или Русский) и нажимаете кнопку «Войти»!
