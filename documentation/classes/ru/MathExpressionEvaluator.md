# Документация класса: MathExpressionEvaluator

---

## 1. Общая информация
- **Имя класса:** `MathExpressionEvaluator`
- **Тип:** Utility Class (Вычислительный парсер)
- **Назначение класса:** Выполняет безопасный разбор и вычисление математических строковых выражений (например, `(7 - 3) / (4 - 2)`).
- **Взаимодействие с другими компонентами:** Используется в `LinearFunctionFragment` и `ParabolaFunctionFragment` для вычисления ответов пользователя.

## 3. Методы класса

### Имя метода: `evaluate(String expression)`
- **Тип метода:** `public static`
- **Возвращаемое значение:** `double` (числовой результат).
- **Параметры:** `expression` (`String` — текстовое выражение, например `"(7-3)/(4-2)"`).
- **Что делает метод:**
  1. Проверяет строку на пустоту.
  2. Заменяет запятые на точки и удаляет пробелы.
  3. Использует парсер рекурсивного спуска для операций `+`, `-`, `*`, `/`, скобок `()` и чисел.
  4. Возвращает число `double` или выбрасывает исключение при ошибке синтаксиса/делении на ноль.

## 8. Объяснение простыми словами
`MathExpressionEvaluator` — это **встроенный калькулятор**. Когда вы печатаете `(7-3)/2`, он разбирает пример, сначала считает $7 - 3 = 4$, а затем делит $4 / 2 = 2.0$!
