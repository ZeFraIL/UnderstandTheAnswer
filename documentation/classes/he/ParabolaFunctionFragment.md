# תיעוד מחלקה: ParabolaFunctionFragment

---

## 1. מידע כללי
- **שם המחלקה:** `ParabolaFunctionFragment`
- **סוג:** Fragment (בקר שיעור)
- **תפקיד המחלקה:** מנהל את שיעור "פונקציה ריבועית": מייצר פרבולות, מחליף מצבים, מפענח ביטויים ומציג מחשבון למערכת משוואות.

---

## 2. מתודות עיקריות
- `generateNewTask()`: מגריל $a_0, x_0, y_0$ ומחשב $b_0, c_0$.
- `checkAnswer()`: מחשב את הביטויים $a, b, c$ ובודק נכונות.
- `showInteractiveSystemDialog(List<Point> points)`: פותח מחשבון למערכת 3 משוואות עם תצוגה חינמית.

---

## 3. הסבר במילים פשוטות
`ParabolaFunctionFragment` הוא **אימון פרבולות**. הוא מחביא פרבולה, נותן 3 כלים לחקירה ובודק את הפרמטרים $a, b, c$ שפתרתם!
