# תיעוד מחלקה: ParabolaFunctionView

---

## 1. מידע כללי
- **שם המחלקה:** `ParabolaFunctionView`
- **סוג:** Custom View (רכיב גרפי ב-Canvas)
- **תפקיד המחלקה:** מצייר פרבולה יעד $y = ax^2 + bx + c$ ו-3 כלי רמז אינטראקטיביים (תבנית-טרנספורמר, ציר סימטריה, 3 נקודות על הגרף).

---

## 2. מתודות עיקריות
- `setTargetFunction(double a, double b, double c)`: מציב את הפרבולה ומחשב את הקדקוד $(x_0, y_0)$.
- `onTouchEvent(MotionEvent event)`: מטפל בגרירת קדקוד תבנית, הזזת ציר סימטריה וחשיפת נקודות.
- `onDraw(Canvas canvas)`: מצייר את הפרבולה ואלמנטי הרמזים.

---

## 3. הסבר במילים פשוטות
`ParabolaFunctionView` הוא **סדנה לפרבולות**. אפשר להזיז שבלונה, להזיז ציר סימטריה או לגלות נקודות כדי לגלות את $a, b, c$!
