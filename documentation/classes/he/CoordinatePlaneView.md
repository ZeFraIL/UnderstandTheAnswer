# תיעוד מחלקה: CoordinatePlaneView

---

## 1. מידע כללי
- **שם המחלקה:** `CoordinatePlaneView`
- **סוג:** Custom View (רכיב גרפי ב-Canvas)
- **תפקיד המחלקה:** מצייר מערכת צירים $[-15..+15]$, חצים, מספרים, נקודת יעד $A$, נקודות רמז אינטראקטיביות ($H_1, H_2$) ואזור אזהרה.

---

## 2. מתודות עיקריות
- `setPoint(int x, int y)`: מגדיר את נקודת היעד $A$.
- `addHintPoint(int x, int y)`: מוסיף נקודת רמז עם בדיקת הגנה מפני מניפולציה ($R \le 2.0$).
- `onTouchEvent(MotionEvent event)`: מפתח מחוות נגיעה וגרירה באצבע.
- `onDraw(Canvas canvas)`: מצייר את הרשת והאלמנטים הגרפיים.

---

## 3. הסבר במילים פשוטות
`CoordinatePlaneView` הוא **לוח נייר מילימטרי דיגיטלי**. הוא מצייר צירים ומאפשר לכם לגרור נקודות רמז כחולות עם האצבע!
