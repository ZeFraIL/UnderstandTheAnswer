# תיעוד מחלקה: MathExpressionEvaluator

---

## 1. מידע כללי
- **שם המחלקה:** `MathExpressionEvaluator`
- **סוג:** Utility Class (מחשב ביטויים)
- **תפקיד המחלקה:** מפענח ומחשב ביטויים מתמטיים מבוססי מחרוזת (למשל `(7 - 3) / (4 - 2)`).

---

## 2. מתודות המחלקה
- `evaluate(String expression)`: מנקה רווחים, בודק תקינות ומחשב את הביטוי באמצעות סורק רקורסיבי עבור `+`, `-`, `*`, `/` וסוגריים `()`.

---

## 3. הסבר במילים פשוטות
`MathExpressionEvaluator` הוא **מחשבון פנימי משובץ**. כשאתם מקלידים `(7-3)/2`, הוא מפרק את התרגיל, מחשב $7-3=4$, ואז מחלק $4/2=2.0$!
