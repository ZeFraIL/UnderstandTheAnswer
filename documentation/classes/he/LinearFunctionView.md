# תיעוד מחלקה: LinearFunctionView

---

## 1. מידע כללי
- **שם המחלקה:** `LinearFunctionView`
- **סוג:** Custom View (רכיב גרפי ב-Canvas)
- **תפקיד המחלקה:** מצייר מערכת צירים, ישר יעד $y = k_0 x + b_0$ ו-3 כלי רמז אינטראקטיביים (ישר מקביל, ישר דרך 2 נקודות, נקודות על הגרף).

---

## 2. מתודות עיקריות
- `setTargetFunction(double k, double b)`: מגדיר את ישר היעד $y = kx + b$.
- `onTouchEvent(MotionEvent event)`: מטפל בגרירת ישר מקביל, גרירת נקודות $P_1, P_2$ או חשיפת נקודות.
- `onDraw(Canvas canvas)`: מצייר את הישרים והרכיבים האינטראקטיביים.

---

## 3. הסבר במילים פשוטות
`LinearFunctionView` הוא **לוח שרטוט לישרים**. אפשר להזיז ישרים מקבילים או למתוח ישר דרך שתי נקודות כדי להבין את השיפוע $k$ וההזזה $b$!
