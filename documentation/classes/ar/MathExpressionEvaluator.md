# توثيق الفئة: MathExpressionEvaluator

---

## 1. معلومات عامة
- **اسم الفئة:** `MathExpressionEvaluator`
- **النوع:** Utility Class (محلل التعابير)
- **وظيفة الفئة:** يقوم بتحليل وحساب التعابير الحسابية النصية (مثل `(7 - 3) / (4 - 2)`).

---

## 2. الشرح بكلمات بسيطة
`MathExpressionEvaluator` هو **محرك حاسبة جيب مدمج**. عندما تكتب `(7-3)/2` يقوم بفك المسألة وحساب $7 - 3 = 4$ ثم قسمة $4 / 2 = 2.0$!
